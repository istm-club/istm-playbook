# ISTM 신입회원 플레이북

Ilsan Standard Toastmasters(ISTM) 신입 회원을 위한 안내 페이지입니다.

- 모임 진행 흐름 (1부 · 2부, 세션별 진행 순서)
- 역할 10개의 할 일과 역할 설명 스크립트 (Toastmasters 공식 Script and Log 기준)
- 패스웨이 레벨1 과정, 첫 스피치(Ice Breaker) 준비, 평가 시트 링크
- 플레이북 챗봇 (AI 없이 플레이북 자료에서 답을 찾아 주는 FAQ형)

보는 주소: https://istm-club.github.io/istm-playbook/

## 파일
- `index.html` — 완성된 페이지 하나 (빌드 결과물)
- `reference/` — 클럽 자료: 신입 회원 가이드, 예시 아젠다(회원 이름과 계좌는 가림)

평가 시트는 Toastmasters International 공식 사이트로 연결됩니다. 시간과 역할 배정은 매 모임 아젠다를 확인하세요.
